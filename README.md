# Ciel

Work in progress AI agent with the following aims:
- **Reasonable footprint**\
  Keep build times and resource usage reasonable.
- **Modularity and extensibility**\
  A lua extension system is planned.
- **Remote-first**\
  Runs as a service accessible through chat platforms or a thin client of your choice.

I was not satisfied with existing projects, so this is my go at it.
The code is written by me, not an LLM.

> [!CAUTION]
> This project is not ready for general use.\
> There are currently no backwards compatibility guarantees.
